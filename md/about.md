Alleviate the deafening silence of the editor with 20+ tactile sound effects for every action.

---

### Mod Compatibility

Additional sound effects have been added for the following mods:

- **[Tinker](mod:alphalaneous.tinker)** by Alphalaneous
- **[BetterEdit](mod:hjfod.betteredit)** by HJFod
- **[Allium Drawing Tool](mod:alk.allium)** by Alk

If a mod isn't supported or doesn't have an appropriate sound for an action, consider [making an issue on GitHub](https://github.com/flurrybun/ninkaz-editor-sfx/issues).

### Customization

**Sound packs** are a simple way to customize sound effects. To import or create your own sound pack, click the **plus button** in the settings menu under the **sound pack** option.

Only `.wav`, `.mp3`, `.ogg`, and `.flac` files are allowed and must be named according to the following scheme:

- `place` <c-9CA0AF>- placing an object</c>
- `delete` <c-9CA0AF>- deleting an object</c>
- `move` <c-9CA0AF>- moving an object</c>
- `transform` <c-9CA0AF>- rotating/flipping an object</c>
- `select` <c-9CA0AF>- selecting an object</c>
- `deselect` <c-9CA0AF>- deselecting an object</c>
- `copy` <c-9CA0AF>- copying an object</c>
- `paste` <c-9CA0AF>- pasting an object</c>
- `duplicate` <c-9CA0AF>- duplicating an object</c>
- `undo` <c-9CA0AF>- undoing an action</c>
- `redo` <c-9CA0AF>- redoing an action</c>
- `lock` <c-9CA0AF>- locking objects/layers</c>
- `unlock` <c-9CA0AF>- unlocking objects/layers</c>
- `toggle-button` <c-9CA0AF>- toggling a setting, e.g. swipe or free move</c>
- `switch-layer` <c-9CA0AF>- switching editor layers</c>
- `switch-mode` <c-9CA0AF>- switching between build, edit, and delete mode</c>
- `switch-tab` <c-9CA0AF>- switching tabs in build mode</c>
- `switch-object` <c-9CA0AF>- switching highlighted object in build mode</c>
- `zoom-in` <c-9CA0AF>- zooming camera in</c>
- `zoom-out` <c-9CA0AF>- zooming camera out</c>
- `slider-tick` <c-9CA0AF>- moving a slider</c>
- `enter-editor` <c-9CA0AF>- entering the editor</c>
- `popup` <c-9CA0AF>- opening a top-level popup</c>

If a certain sound effect file isn't present, it will fall back on the default sound pack, which is useful if you only want to change a few sounds.
